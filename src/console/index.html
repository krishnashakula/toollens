02 · Catalog

Many servers. Overlapping names.

Tools are indexed by name, description, schema and server identity. Real catalogs repeat names across servers, so every tool is addressed by its full id: server/tool.

Names collide. Ids don't.

The same tool name exposed by several servers means different things on each. The agent never has to guess which one; discovery returns full ids.
